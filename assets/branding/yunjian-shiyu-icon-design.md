# 云间拾语图标

当前采用用户提供的 `yunjian-brand` 图标包，主题为“云间托起一句话”：青碧色云带向内回旋，以留白托起暖杏色语滴。图稿直接沿用，未重绘路径或调整颜色。

## 资源对应

- `assets/branding/yunjian-shiyu-icon.svg`：浅色主标原稿。
- `assets/branding/yunjian-shiyu-icon-dark.svg`：深色主标原稿。
- `assets/branding/yunjian-shiyu-icon-mono.svg`：单色原稿。
- `assets/branding/yunjian-shiyu-favicon.svg`：专用小尺寸图标原稿。
- `assets/branding/yunjian-shiyu-icon.png`：提供的 1024 × 1024 透明 PNG 原稿。
- `assets/branding/yunjian-brand-source.txt`：图标包原始说明。
- `claude_chat/ui/icons/yunjian-shiyu.svg`、`yunjian-shiyu-dark.svg`：页面浅色、深色主标，随应用主题切换。
- `claude_chat/ui/icons/yunjian-shiyu-favicon.svg`：网站标签图标，按图稿内置规则跟随系统配色偏好。
- `claude_chat/ui/icons/yunjian-shiyu.ico`：图标包提供的 ICO，网页兼容、桌面窗口和 PyInstaller 使用此文件。
- `claude_chat/ui/icons/yunjian-shiyu.png`：从提供的 PNG 导出的 256 × 256 兼容资源。
- `claude_chat/ui/icons/yunjian-shiyu-180.png`：从提供的 PNG 导出的 180 × 180 Apple touch icon。

SVG、ICO 和原稿 PNG 均与提供的图标包逐字节一致；只有两个 PNG 兼容尺寸经过缩放。原 Chatudex 图稿留存。
